# Proyecto TechConf

Web de conferencias de tecnologia realizada con **bootstrap v5.3**, **HTML** y **CSS**

## 💻 Demo del proyecto

Mira la demo del proyecto [aqui](https://techconf-c30.netlify.app/)

## 🛠️ Herramientas utilizadas

- HTML5
- CSS3
- [Bootstrap v5.3](https://getbootstrap.com/docs/5.3/getting-started/introduction/)

## 📖 Pasos para probar el proyecto

Segui los siguientes pasos para probar el proyecto en forma local:

1. Clona el repositorio usando el siguiente comando:  
   ```git clone https://github.com/rollingcodeschool/techConf-c30.git```

2. Abre el proyecto con tu IDE favorita, por ej: vscode
3. Ver en el browser el archivo index.html
